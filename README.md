# Vector3D visualizer

Vector3D is a Python-based desktop application built with Tkinter and Matplotlib that allows users to perform algebraic operations on 3D vectors and visualize them in a dynamic 3D space. 

Whether you need to find a unit vector, calculate the distance between two points, or find the section division of a line, this tool provides both the mathematical output and an interactive 3D plot.

---

## Features

* **1-Vector Operations:** * View standard vector component representation ($i,j,k$).
  * Calculate and plot the Unit Vector.
* **2-Vector Operations:**
  * Vector Addition & Subtraction.
  * Distance calculation (provides exact decimal and simplified radical forms like $a\sqrt{b}$).
  * Mid-point calculation.
  * Internal and External Section Division using custom ratios ($m:n$).
  * Vector Line Equation generation ($r = a + \lambda b$).
* **Interactive 3D Plotting:** Automatically updates a Matplotlib 3D canvas showing the vector arrows, paths, and points against a clean, dark-themed UI.
